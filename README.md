# AI Rural Healthcare Assistant

An AI-powered healthcare chatbot designed for rural communities and ASHA health workers. The system helps users understand symptoms through a simple conversation and guides them on whether to take home care, visit a Primary Health Center, or go to a hospital.

## Features

- Chatbot-based symptom checker
- Emergency red flag detection
- Home care recommendations based on symptoms
- Nearby hospital and health center guidance
- Patient history tracking
- Multi-language support (English, Hindi, Tamil)
- Simple interface designed for rural users
